# ABOUT

This is a mod for Factorio that reworks beacon mechanics to be similar to Space Exploration/Beacon Overload type mods, but slightly less restrictive.

The mod adds several new types of beacons. Any production machine affected by multiple of the same type of beacon has their influences averaged together; however, different types of beacons affecting the same machine stack.

- Vanilla beacon: base distribution efficiency reduced, quality benefits reduced, otherwise the same.
- Breaker box: only accepts efficiency modules, has a large distribution area, and does not require any electricity.
- External drive unit: only accepts speed modules. Only affects directly adjacent machines and consumes lubricant to function. Unlike other beacon types, up to 4 can affect the same machine at once.
- Torment Nexus: Acts over a very large area. Has an integrated roboport.

Additionally, an optional feature of Overclocked Modules can be enabled. These modules have impressive effects, but have a limited lifespan and must be periodically replaced, taking advantage of the normally mostly useless ability for inserters to interact with beacons. Because of its dependency on the spoilage mechanic, this feature cannot be used without either Space Age or the Enable All Feature Flags mod.

- Overclocked efficiency module: extreme energy reduction and a small speed buff.
- Overclocked speed module: high speed buff and no quality penalty.
- Overclocked quality module: only quality module to be usable in beacons at all and has no speed penalty.
